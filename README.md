# Nycollas Holanda — Portfólio

Portfólio pessoal moderno e minimalista com foco em alto desempenho, criado com código limpo e arquitetura de alto contraste (estilo Vercel e Linear).

🔗 **Site:** [nycollasholanda.github.io/Portfolio](https://nycollasholanda.github.io/Portfolio/)

![Preview do portfólio](assets/Logo_portifolio.jpe)

## Sobre o projeto

Uma vitrine digital de página única projetada para apresentar minha atuação em desenvolvimento de software (Web, Mobile e Backend) e infraestrutura de redes. O design foca em tipografia refinada (Geist / Geist Mono), estética escura de alto contraste e microinterações táteis e discretas, dispensando o uso de frameworks pesados para garantir carregamento instantâneo.

## Tecnologias

- **HTML5 semântico** (SEO e acessibilidade)
- **CSS3 moderno** (Variáveis, Flexbox, CSS Grid, Media Queries)
- **JavaScript Vanilla** (Interações de glow no cursor, scroll reveal e manipulação da Clipboard API)
- **Tipografia:** [Geist Sans & Geist Mono](https://vercel.com/font) via Google Fonts

## Funcionalidades

- **Iluminação interativa (Glow):** Efeito de luz radial suave que reage ao cursor do mouse.
- **Scroll Reveal:** Animações sutis e progressivas de entrada à medida que o usuário rola a página.
- **Ações rápidas de contato:** Botão interativo para cópia de e-mail com feedback visual e atalhos diretos para GitHub, LinkedIn e WhatsApp.
- **Visualizador de currículo:** Acesso direto ao PDF hospedado no Google Drive.
- **Totalmente responsivo:** Adaptado para diferentes resoluções, de telas mobile a desktops widescreen.
